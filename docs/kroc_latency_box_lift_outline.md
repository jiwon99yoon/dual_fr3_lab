# KRoC 원고 골격: Delay-Robust RL for Zero-Shot Sim-to-Real Dual-Arm Box Lifting

작성 2026-11-13 (4090). 결과 수치는 `docs/dual_fr3_curriculum_eval.md` §7이 원본이고, 여기에는 원고 흐름과 해야 할 실험만 둔다.

## 0. 제목 (2026-11-13 결정안)

- 영문: *Delay-Robust Reinforcement Learning for Zero-Shot Sim-to-Real Transfer in Dual-Arm Box Lifting*
- 국문: 지연에 강건한 강화학습 기반 양팔 박스 들기의 Zero-Shot Sim-to-Real 전이
- 대안(실물 결과가 약할 때): *Delay-Robust Reinforcement Learning with System Identification for Contact-Rich Dual-Arm Box Lifting*
- 제목이 zero-shot을 약속하므로 실물 성공률 표(추가 학습 없이)가 필수다. 제어 모드(위치/토크)는 제목에 넣지 않고 SysID 절에서 다룬다.
- zero-shot 정의: 정책은 실물 데이터로 학습·미세조정하지 않는다. SysID는 관절 추종 응답(스텝·사인 등)만 쓰고,
  박스 들기 실물 시도는 SysID·재학습에 쓰지 않는다. 판-박스 마찰·박스 질량은 SysID가 아니라 DR로 다룬다. SysID는 제어 모드별로 따로 한다.
- 제어 모드 정의(11-13 확인):
  - **토크 모드 = 지금 구조.** 정책은 관절 목표 위치를 내고, PD(τ = Kp(q_target − q) − Kd·q̇, 어깨 Kp 80 / Kd 4, 토크 변화율
    1000 Nm/s, `TorqueRateLimitedPDActuator`)로 토크를 만들어 FR3 토크 인터페이스로 보낸다. 지금 지연 DR(관절 상태·명령)은 이 구조 위에 있다.
  - **위치 모드 = FR3 관절 위치 인터페이스.** 목표 위치를 보내면 FR3 내부 제어기(자체 게인·필터·궤적 제한)가 추종한다. sim에 모델이 없다.
    필요한 것: 실물 위치 모드 스텝·사인 응답 SysID → sim 액추에이터(게인·지연·필터)를 맞춤 → 그 sim으로 별도 학습 → 그 모드의 지연 실측을 DR에 반영.
  - 위치 모드가 마감 전에 안 되면 토크 모드만 쓰고 제목은 그대로 둔다.

## 1. 주장 (contribution, 3개 이내)

1. 양팔 판 박스 들기에서 지연을 **종류별로 분해**한다(비전 박스 pose / 관절 상태 / 명령). 각 지연이 학습과 전이에 미치는 영향을
   학습 조건 × 평가 조건 행렬로 정량화한다.
2. 지연 DR은 **정밀도와 강건성을 맞바꾼다.** 근거(sim, model_5999, 256 env, 지연 있는 평가):
   - 지연 없이 학습한 정책: 지연 없는 sim에서 goal 5 cm 성공 96.9%. 지연이 들어가면 놓침 48회.
   - 지연 넣어 학습한 정책: 놓침 3회. 대신 5 cm 성공은 81~83%.
3. 단계형 커리큘럼(벌점 → goal xy → 저마찰 → 호버 시작)으로 처음부터 학습한다. **비전 지연이 저마찰 단계의 병목**이다(남은 run으로 확인).
   이 정책을 실로봇에 전이한다.

## 3. 방법 절에 쓸 내용 (v2 `params/env.yaml` 기준)

### 3.1 문제 설정
- FR3 두 대, link7에 평판. 그리퍼 없이 두 판으로 박스를 조여 든다.
- 박스 310 × 410 × 280 mm, 0.4~0.6 kg.
- 시작 두 가지: MoveIt 접근 자세(판이 박스 면 4 cm 밖) / 박스 위 0.25 m 호버 자세.
- 목표: 박스 중심을 x 0.40~0.50, y ±0.10, 높이 0.15~0.35 m로. 에피소드 6 s.

### 3.2 관측·행동
- actor 56D: 관절 위치 14(지연), 관절 속도 14, 박스 위치 3(지연·끊김·오프셋), 박스 자세 4(같음), 목표 위치 3, 이전 행동 14.
- critic 70D: actor 관측(지연 없는 값) + DR 특권값 14 (asymmetric actor-critic).
- 행동: 관절 위치 목표 변화량 14, scale 0.1, clip ±0.1 rad. 정책 20 Hz, 물리 100 Hz(decimation 5).
  목표는 정책 step 동안 유지, 토크 변화율 제한 1000 Nm/s.
- PPO(rsl_rl), tanh-squashed Gaussian actor, 4096 env, 6000 iter(4090에서 약 2.7~3 h).

### 3.3 보상 (표 1, 가중치가 실질적인 항만)

| 분류 | 항 | 가중치 |
|---|---|---|
| 접근 | 판-박스 정렬 접근 (`reaching_aligned`, std 0.3) | +6 |
| 조이기 | 양판 접촉 힘 품질 (`squeezing_quality`) | +2 |
| 들기 | 양판 조인 상태로 10 cm 이상 들기 / 들기 진행도 | +15 / +8 |
| 목표 추종 | goal 거리 커널 (std 0.3 / 0.05, 양판 조인 상태에서만) | +16 / +5 |
| 성공 | goal 10 cm·기울기 15°·yaw 정렬을 10 step 유지 | +20 |
| 자세 | 박스 기울기 / 두 판 어긋남 | −2 / −4 |
| 안전 | 판이 박스 윗면 접촉(호버 시작용) / 관절 한계 여유 / J1 좌우 대칭 | −5 / −1 / −1 |
| 커리큘럼 벌점 | shaping a/b (action rate, 속도, 비판 접촉 등, 단계형으로 켜짐) | −20 / −10까지 |

- 원고에는 "들기·목표 보상은 양판이 1 N 이상 접촉한 상태에서만 준다"(조이지 않고 밀어 올리는 국소해 방지)를 한 줄로 쓴다.
- 커리큘럼 벌점 항 이름과 최종 가중치는 `_apply_box_curriculum`에서 다시 확인해 표에 넣는다.

### 3.4 문제 정식화·지연 모델 (원고 문안, 11-13 확정)

> **POMDP** 실제 상태에는 박스 마찰·질량·크기와 접촉력이 포함되나, 정책은 노이즈가 섞인 일부 관측만 봄
>
> **비대칭 actor-critic** 실로봇에 배포되는 actor는 측정 가능한 정보만, 학습에만 쓰는 critic은 정확한 박스 pose와 DR 값(마찰·질량·크기·게인·지연)을 봄
>
> **Actor 입력에 비전 오차 모사**
> - 지연: 에피소드마다 0–3 policy step(0–150 ms) 중 하나로 고정
> - 끊김: step마다 2% 확률로 시작, 0.1–1 s 동안 마지막 값 유지 (에피소드 10%는 도중부터 끝까지)
> - 고정 오프셋: 에피소드마다 위치 ±1 cm, yaw ±3°
>
> **관절 상태 및 명령 지연**
> - 관절 지연: 정책이 보는 관절 위치가 실제보다 과거 값 (0–10 ms 연속값)
> - 명령 지연: 정책이 낸 목표가 PD 토크 제어에 늦게 들어감 (0 또는 10 ms, 물리 0/1 step)
>
> PhysX 100 Hz, Policy 20 Hz, 에피소드 6 s(120 step) / 종료: 시간 초과 또는 박스가 작업 영역을 벗어남

구현 메모:

| 지연 | 범위 | 정하는 시점 | 구현 | ablation task |
|---|---|---|---|---|
| 비전 지연 | 0/50/100/150 ms (`BOX_OBS_DELAY_STEPS` 3) | 에피소드 시작 | `object_*_dropout_biased` | `-NoVisionDelay` (끊김도 같이 off, 오프셋·노이즈는 유지) |
| 비전 끊김 | step당 2% 시작, 2~20 step 유지, 에피소드 10% 끝까지 (`BOX_OBS_DROP_*`, `BOX_OBS_FULL_DROP_PROB`) | 매 step | 같음 | 같음 |
| 관절 상태 | 0~10 ms 연속, `q − q̇·d` 1차 근사 | 에피소드 시작 | `DelayedReachRelativeJointPositionAction.obs_delay` | `-NoJointDelay` (명령과 함께) |
| 명령 | 0 또는 1 물리 step: 정책 step의 첫 10 ms 동안 이전 목표 유지 | 에피소드 시작 | `...cmd_delay` (manifest `trained_command_delay_s`) | `-NoJointDelay` (관절 상태와 함께) |

- 예전 문서의 "명령 지연(위치 제어단)" 표현은 틀렸다. 명령 지연은 토크 모드 PD 루프에 들어가는 목표의 지연이다. 위치 모드는 §0 참고.
- 실측값과 나란히 적을 것: 실로봇 비전 지연 35~90 ms(rosbag) → 학습 범위 0~150 ms. 관절·명령 지연도 rosbag에서 잰다.
- 명령 지연만 따로 보려면 `-NoCmdDelay` ablation이 필요하다(지금 `-NoJointDelay`는 둘을 같이 끈다).

### 3.5 DR·커리큘럼 (표 2)
- startup DR: 박스 크기 ±3%, 질량, 박스·판 마찰, 액추에이터 게인, FR3 데이터시트 관절 한계. interval: 박스 외란 렌치.
- 커리큘럼 단계와 전환 성공률: shaping a(0.10) → shaping b → goal xy(0.20) → 마찰(0.30) → 호버.
  성공률이 기준 아래로 내려가면 멈춘다. 동시 전환 run 1은 붕괴했다(한 줄 근거로 쓴다).

   - `eval_dual_fr3_plate_robustness.py`에 고정 지연 옵션을 추가해야 한다.
3. **학습 곡선 비교 (그림 3):** 저마찰 단계 성공률 붕괴 폭과 모든 단계 완료 iter.
   - v2: 0.25, 4517 it / NoDelay: 0.69, 3723 it / NoVisionDelay: 0.60 at 2000 it, 진행 중.
   - TB `Curriculum/schedule/*`에서 바로 뽑는다.
4. **실로봇 (표 4):** v2 vs NoDelay(가능하면 NoVisionDelay도), 같은 박스 위치·같은 시도 수(각 10회).
   - 기록: 성공·놓침·미끄럼 거리, rosbag에서 실측 지연.
   - sim 행렬의 순위가 실물 순위와 맞는지가 sim2real 분석의 결론이 된다.
5. **제어 모드 비교:** 같은 정책·같은 지연 조건에서 위치/토크 모드 성공률과 추종 오차. 모드 정의가 정해진 뒤 설계한다.

## 7. 논의 기록 (11-13, 원고 범위 밖이지만 질문 대비)

- **"분석" 수준:** 제목에서 Analysis를 뺐으므로 ablation은 "지연 DR이 왜 필요한가"의 근거 실험 한 절로 충분하다. 4.3의 seed 반복·지연 sweep은 여력이 될 때.
- **SysID와 zero-shot:** 실물 데이터로 시뮬레이터(관절 응답)만 보정하고 정책은 sim에서만 학습하면 zero-shot이라 부를 수 있다(Tan 2018, Hwangbo 2019).
  박스 들기 실물 시도를 SysID·재학습에 쓰면 real-to-sim 반복이 되어 zero-shot이 아니다.
- **비전 sim2real(질문 대비):** 지금은 박스 pose를 외부 추정기(실물)로 받고 sim은 그 오차(지연·끊김·오프셋·노이즈)만 모사한다.
  대안: 학습된 pose 추정기(SAM 계열 분할 + pose, 또는 bounding box)로 교체, 또는 privileged teacher → 이미지 student 증류. 이번 원고 범위 밖.
- **토크 기반 마찰·질량 추정(향후 연구):** 5070 `docs/dual_fr3_torque_adaptation_study.md`. 결론 절의 향후 연구로 한 줄.
