# 박스 들기 토크 기반 파라미터 추정 예비 연구 (2026-11-13)

후속 주제 후보 "관절 토크 기록으로 박스 무게·마찰을 추정해 조임을 조절하는 모듈(RMA식)"이 성립하는지, 실물 시간을 쓰지 않는
두 단계만 먼저 확인했다. 결론: **무게는 들기 시작 0.25 s 안에 토크·운동 기록으로 ±0.1 kg까지 보이지만, 마찰은 이 정책의
들기 구간만으로는 전혀 안 보인다.** 마찰까지 다루려면 탐색 동작(조임을 줄여 미끄럼 시작을 찾는 식)이 필요하다.

## 1단계. 실물 bag: 들기 순간 외력에 무게가 보이는가, 미끄럼은 보이는가

- 데이터: etri `data/dual_fr3_boxlift_real_bags` 11-05 bag 12개(3998 FlatSqueeze 10, 6697 SqueezeLift 2). 박스 0.50~0.56 kg.
  표준 메시지만 읽음: `/dual_fr3/joint_states`(tau_J 1 kHz), `/{left,right}_…/external_wrench_in_base_frame`(1 kHz), `/box_tf`(30 Hz),
  `/policy_joint_command`(20 Hz). `FrankaRobotState`(tau_ext_hat)는 이 PC에 franka_msgs가 없어 못 읽었다.
- 스크립트: etri `scripts/tools/analyze_boxlift_bag_lift_onset.py` → 요약 CSV + 그림(들기 전후 2 s).

| 항목 | 값 (3998 10 run 중앙값) | 비고 |
|---|---|---|
| 조임 외력 (각 팔 Fy) | 16~18.5 N | sim 조임 16 N과 같음 |
| 들기 전 수직 외력 (각 팔 Fz, 아무것도 안 닿음) | −4 N | 판 질량이 Franka payload에 없어서 생기는 bias |
| 들기 뒤 수직 외력 변화 (양팔 합) | +17~20 N (예상 −m g = −5.2 N) | 부호·크기 모두 어긋남. 판이 기울며 조임 힘의 수직 성분이 섞이고 Fx도 +2 → −12 N로 자세 따라 흐름 |
| run 간 편차 (같은 박스) | 17.2~19.6 N (표준편차 0.8 N ≈ 80 g) | 반복성은 좋음 → 실물 데이터로 보정하면 쓸 여지 |
| 판 TCP 상승 − 박스 상승 (t_lift −0.1 → +0.5 s) | 7~11 cm (6697 2~5 cm) | 미끄럼은 관절각 FK + 박스 pose만으로 명확 |
| 박스 기울기 최대 | 40~116° | |

해석: (1) 미끄럼은 토크 없이도 정책 관측(관절각·박스 pose)으로 바로 보인다. (2) 외력 추정치는 무게(5 N)보다 큰 자세 의존
bias를 가지므로, 실물에서 무게를 읽으려면 Franka payload 설정(판 질량·무게중심)과 자세별 bias 모델이 먼저다.
(3) 11-07 5499 성공 세션은 trace(20 Hz 관측·행동)만 있고 bag이 없어 "성공적으로 든 뒤 토크"는 실물 데이터가 없다.

## 2단계. sim: 토크 기록으로 무게·마찰을 회귀할 수 있는가

- 데이터: GoalXY-Play(`…-LowMuSoftLift-GoalXY-Play-v0`)에서 5499 정책 결정적 rollout, 512 env × 4 라운드 = 2048 에피소드(4 s, 20 Hz).
  라운드마다 질량 0.3~1.5 kg(abs), 박스 마찰 0.1~0.8, 판 마찰 0.3~0.5를 다시 뽑음(startup DR 항을 runtime에 재적용).
  기록: q, dq, applied torque(14), 판 접촉력 L/R, 박스 dz·vz, 행동. 스크립트 `scripts/tools/collect_box_torque_history.py`.
- 회귀: 들기 시작(박스 +3 cm) + k step에서 끝나는 0.5 s 창을 MLP(128×2)에 넣어 질량 / 박스 마찰 / 접촉 마찰(PhysX average)을
  예측, 20 % 홀드아웃, 3 seed 평균. 실물 흉내 손상 = 관절별 상수 bias N(0, 1 Nm) + 백색 0.3 Nm. `scripts/tools/fit_box_param_estimator.py`.

| 입력 (창 0.5 s, k = 0.25 s) | 질량 MAE [kg] (R²) | 손상 시 | 박스 마찰 MAE (R²) | 접촉 마찰 MAE (R²) |
|---|---|---|---|---|
| 평균 예측 (기준) | 0.30 | | 0.17 | 0.088 |
| q, dq, 행동 (History 정책이 보는 것) | 0.12 (0.79) | 0.12 | 0.18 (−0.17) | 0.091 (−0.16) |
| + 관절 토크 | **0.09 (0.85)** | 0.13 (0.76) | 0.17 (−0.11) | 0.089 (−0.13) |
| + 토크 + 박스 dz/vz | 0.09 (0.85) | 0.12 | 0.17 (−0.12) | 0.089 (−0.18) |
| 토크만 | 0.11 (0.81) | 0.18 (0.57) | 0.19 (−0.49) | 0.092 (−0.41) |

- 창 끝 시점 k = 0 / 0.25 / 0.5 / 1.0 s 모두 비슷(질량 0.09~0.11). 1 Nm bias가 들어가면 토크의 이득이 사라져 운동학만과 같아진다.
- 마찰은 어느 입력·창·부분집합(무거운 박스만, 든 것만, 2 s 창)에서도 R² ≤ 0. 결과(들렸는가)는 여유 = 2 μ F − m g와 상관 0.77이지만
  조임이 거의 일정(양판 합 29 N)해서 μ 자체는 분리되지 않는다. 창에서 "들렸는가"는 R² 0.96으로 거의 완벽히 읽힌다.
- 5499의 무게 여유: 0.3~0.6 kg 100 %, 0.6~0.9 76 %, 0.9~1.2 36 %, 1.2~1.5 7 % (낮은 μ<0.35면 0.9 kg 이상은 4 % 이하).

## 결론과 다음

1. **무게 적응**은 성립한다. 토크 없이도 운동학 기록에 무게가 보이므로(정책 반응이 달라서) `-History-v0`가 암묵 적응 기준선이 되고,
   토크를 추가하면 clean sim에서 25 % 개선, 실물급 bias에서는 이득 없음 → 실물 bias 보정(payload 설정·bias 모델)이 선행 조건.
2. **마찰 적응**은 "들기 중 추정"으로는 안 된다. 탐색 동작(들기 전 조임을 낮춰 미끄럼 시작 힘을 재기)이나 미끄럼 감지 → 조임 증가의
   반응형 규칙이 맞다. 미끄럼 감지는 1단계대로 관절각·박스 pose로 충분하다.
3. 논문으로 가려면: (a) 실물 payload 보정 + 무게 3단계 × 마찰 3단계 데이터, (b) 탐색 동작을 넣은 교사·학생 학습, (c) 고정 DR(v2)·History·
   교사 상한 비교. 지금 자산으로는 (1)의 "무게는 보인다, 마찰은 안 보인다"가 결과다.
